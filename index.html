Cara pasang APK di Android

APK ialah fail pemasangan Android. Anda hanya perlu benarkan pemasangan daripada browser sekali sahaja.

  1. Tekan butang APK pada kad aplikasi. Fail akan dimuat turun.
  2. Buka fail tersebut (dari notifikasi atau aplikasi Files).
  3. Jika muncul amaran, tekan Settings → hidupkan Allow from this source.
  4. Tekan Install → Open.

Amaran Play Protect?

Ini muncul untuk semua APK di luar Play Store, bukan tanda aplikasi berbahaya. Tekan Install anyway / Install tanpa mengimbas. Setiap APK di sini ditandatangani dengan kunci rilis saya sendiri.

Versi Android minimum

Android 6.0 (Marshmallow) ke atas. Jika fail arm64 gagal, cuba versi universal.

iPhone?

Aplikasi iOS diedarkan melalui App Store sahaja — tekan butang App Store pada kad aplikasi.
